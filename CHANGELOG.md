# Changelog

All notable changes to this project are documented in this file.

## v0.9.0-rag-evaluation

### Added

- Fixed RAG benchmark dataset.
- Retrieval evaluation metrics.
- Hit Rate@K.
- Recall@K.
- Mean Reciprocal Rank.
- Deterministic benchmark runner.
- Experiment comparison utilities.

## v0.9.0-type-safety

### Added

- Static type checking with mypy.
- Type-safety baseline for application code.

## v0.8.0-ml-reproducibility

### Added

- Reproducible experiment baseline.
- Experiment configuration.
- Global random seed support.

## v0.7.0-observability

### Added

- Structured application observability.
- Prometheus metrics support.

## v0.6.0-backend-validation

### Added

- Prompt validation.
- Backend safeguards.
- Additional validation coverage.

## v0.5.0-scorer-visibility

### Added

- Dependency validation improvements.

## v0.4.0-application-coverage

### Added

- Expanded Flask application test coverage.

## v0.3.0-rag-integration

### Added

- Deterministic RAG pipeline integration testing.
